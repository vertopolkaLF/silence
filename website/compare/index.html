How to pick one without losing your mind

One hotkey, default mic

SoundSwitch. You probably already want its device switching. Mute is a bonus key.

See the mute state

Anything with a real overlay: silence!, MicControl, AHK MicMute, YouAreMuted, MuteDeck.

Games + controller

silence! is the one that actually binds a gamepad. Skip AutoHotkey if the game’s anti-cheat is spicy.

Meetings all day

MuteDeck if you want camera/leave and a Stream Deck. Mutto if you want a phone button on Windows 11.

Mute your mic with silence!

silence! mutes the selected microphone — or every active one — at the Windows device level. Overlay and tray show the state. Hold-to-mute covers coughs. Gamepad covers the raid where the keyboard is a continent away.

FAQ

If you only need one hotkey for the default microphone, SoundSwitch is enough. If you want an on-screen mute state, hold-to-mute, mouse buttons, all microphones, or a gamepad, use a dedicated mute app such as silence!.

MuteDeck is for meeting-app controls and Stream Deck. Mutto is Windows 11 only and adds a phone button.

SoundSwitch is built to switch playback and recording devices. It also has a mute hotkey, default Ctrl + Alt + M, and optional mute banners. It does not do hold-to-mute or gamepad bindings.

Microsoft removed Video Conference Mute in PowerToys 0.88.0 in January 2025. Older guides still mention Win + Shift + A. That shortcut is gone. Use Windows Sound settings, a hardware mute key, or a dedicated mic mute app.

MicMute is a generic name. The AutoHotkey one by SaifAqqad has profiles and an overlay. itsnateai/MicMute is a .NET tray app with push-to-talk. iAlturki/MicMute is a tiny overlay utility. They are unrelated projects. Please, nobody name the next one MicMute.
